│ updated_at      │ TIMESTAMP    │ Auto     │
└─────────────────┴──────────────┴──────────┘

TABLE: admin_audit_log
┌──────────────┬──────────┬────────────────────┐
│ Column       │ Type     │ Notes              │
├──────────────┼──────────┼────────────────────┤
│ id           │ UUID     │ Primary            │
│ admin_id     │ UUID     │ Foreign key        │
│ action       │ VARCHAR  │ create/update/etc  │
│ entity_type  │ VARCHAR  │ 'geographic_node'  │
│ entity_id    │ UUID     │ Foreign key        │
│ changes      │ JSONB    │ Before/after       │

└──────────────┴──────────┴────────────────────┘

RLS POLICIES:

- Admin audit log for all writes
