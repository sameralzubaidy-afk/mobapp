# Assets Images Folder

This folder contains image assets for the Pass It Up mobile app.

## Logo Instructions

**File:** `app-logo.png`  
**Purpose:** Main app logo displayed on the Landing Screen  
**Specifications:**
- Size: 120x120 pixels (or larger, will scale down)
- Format: PNG with transparent background
- Design: Green network graph with "P" center icon (from Figma)
- Location: Replace the handshake emoji on Landing Screen

**How to Add:**
1. Save the logo image from Figma as `app-logo.png`
2. Place it in this folder: `p2p-kids-marketplace/assets/images/`
3. The LandingScreen will automatically load it
