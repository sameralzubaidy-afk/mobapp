# Feature & Function Inventory — Kids Marketplace App

Generated by scanning the codebase directly (screens, services, navigation, admin routes, API endpoints, Supabase edge functions). Reflects what is built in code as of 2026-09-12, not what's necessarily finished/bug-free.

---

## 1. Mobile App (`p2p-kids-marketplace`) — React Native / Expo

### Auth & Onboarding
- Landing screen, Login, Signup, Forgot/Reset password
- Phone number verification (OTP)
- Onboarding flow (multi-step intro)
- Google Sign-In and Apple Sign-In (OAuth)
- Suspended-account handling screen
- Account deletion flow

### Home, Discovery & Browse
- Home dashboard with personalized greeting, node (pickup location) chip
- Discover feed with header/search
- Category browse screen
- Item detail screen
- "More from this seller" screen
- Search with search-history recall
- Brand autocomplete on listing/search forms
- Favorites (save/unsave items, favorites list)

### Listings (Selling)
- Create single listing (`ItemCreateScreen`)
- Bulk listing creation (multi-item at once)
- Edit listing
- My Listings management screen
- Draft system (save drafts, bulk-publish drafts)
- Condition guide service (standardized item condition descriptions)
- Listing safety review screen (pre-publish safety check, likely tied to CPSC recall/image moderation)
- AI-assisted item analysis (single + batch image analysis via `aiService`)
- Image moderation before listing goes live

### Cart & Checkout ("Trade Basket")
- Trade Basket cart (multi-item, multi-seller aware)
- Bundle builder — combine multiple items from the same seller into one offer
- Cart checkout screen with order summary (subtotal, platform fee, tax, total)
- Per-item Swap Points (SP) redemption inputs with category-based caps
- Saved payment method selection at checkout

### Trades & Offers
- Trade offer creation / initiation
- Trade list (buyer "Your Offers" / seller "Needs Action" / in-progress / completed, with live badge counts)
- Review Offer screen (seller accept/decline, per-item and bundle-level payout breakdown)
- Trade detail & Trade timeline (status stages: initiated → in progress → completed)
- Trade success / confirmation screen
- Accept/decline bundle offers (whole bundle or item-by-item)
- Cancel trade (buyer/seller, reason codes, refund/SP-reversal logic)
- Issue reporting modal (report a problem mid-trade)
- Dispute-adjacent flows (surfaced primarily via admin, see below)
- Trade review/rating submission after completion
- 48-hour offer expiry countdown

### Payments
- Stripe-based checkout (saved cards, add payment method)
- Payment methods management screen
- Payment retry handling (failed payment recovery)
- Sales tax calculation (jurisdiction-based, tax-exempt category support, e.g. exempt "Books")
- Liability disclaimer / terms acceptance before sending an offer

### Swap Points (SP) — Loyalty/Points Economy
- SP wallet (balance, reserved vs. available)
- SP transaction history
- Earning SP (from completed trades)
- Spending SP as partial payment, capped per item category (50/70/75% caps seen in QA)
- SP expiration logic
- SP reservation/release on trade offer, cancel, decline

### Subscriptions ("Kids Club")
- Plan comparison screen
- Join / upgrade / manage / cancel subscription flows
- Subscription payment & success screens
- Trial period support (conversion, extension, reminders)
- Billing history screen
- Subscription status / expired-state handling
- Grace period handling for failed renewal payments

### Payouts & Seller Earnings
- Seller earnings dashboard
- Request payout screen
- Payout settings (bank/PayPal linking)
- Payout dashboard (status of pending/completed payouts)
- Seller balance tracking

### Messaging
- Conversations list
- 1:1 chat screen per trade/listing
- Real-time messaging (Supabase Realtime)
- Automated message cleanup (stale/old message purge)

### Reviews & Reputation
- Submit review after a trade
- Seller profile with review display
- Review moderation hooks (reported reviews flow to admin)

### Notifications
- In-app notification center
- Notification preferences screen (granular per-category toggles)
- Push notifications (Expo/APNs/FCM via `expo-notifications`)
- Email notifications (trade updates, subscription, referral)
- SMS notifications
- Notification analytics (delivery/engagement tracking)
- Deep-linking from notifications into the right screen

### Profile & Account
- Profile view/edit, profile setup (first-run)
- Settings screen (account, privacy, notifications)
- Linked accounts (OAuth providers)
- Privacy Policy / Terms of Service in-app viewers
- ID verification upload (photo ID for trust/safety)
- ID badge display on profile
- Badges screen (achievement/gamification badges) + leaderboard

### Referrals
- Referral code generation & sharing (v2 system)
- Referral rewards (bonus SP/credit for successful referrals)
- Referral notifications

### Safety & Trust
- Item safety checks (CPSC recall cross-reference, image moderation)
- ID verification review workflow
- Report/flag content

### Support & Help
- Help screen / Help & Support menu
- FAQ detail screens
- Contact Support form
- Unsubscribe (email) landing screen

### In-App Admin/Dev Screens (bundled inside the mobile app, not the separate admin web app)
- Admin dashboard screen
- Moderation queue screen
- Node (pickup location) management screen
- Review moderation screen
- Trial conversion / trial extension test screens (QA/dev tooling)

### Cross-Cutting
- Bottom tab navigation: Home / Discover / Sell / Trades / Basket
- Global alert provider (app-wide modal/toast system)
- Offline-state screen
- Generic error/success feedback screens
- Location services (node/pickup-point resolution)
- Zustand user store + React Context for Auth and Cart state
- Analytics instrumentation (Amplitude) + crash reporting (Sentry)
